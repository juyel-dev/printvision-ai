# PrintVision Tiny

**Lightweight, browser-first Tiny Vision AI** that understands educational PDF pages and powers a Rust/WASM engine to generate high-quality print-ready PDFs **completely offline**.

![PrintVision Banner](https://via.placeholder.com/1280x640/0a2540/00d4ff?text=PrintVision+Tiny+-+Document+AI+for+Print)  

## ✨ Key Capabilities
- **PDF Understanding**: Layout analysis, text, figures, educational structures via Tiny Vision model.
- **Print Optimization**: Intelligent preprocessing for high-fidelity print-ready output.
- **Offline & Browser-First**: Rust + WASM core, no cloud dependency.
- **Modular Design**: Easy model/dataset replacement, reproducible pipelines.
